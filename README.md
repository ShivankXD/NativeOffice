# NativeOffice releases

Download builds of [NativeOffice](https://nativeoffice.online) for Windows live under
[Releases](https://github.com/ShivankXD/NativeOffice-Releases/releases). Each release
carries `NativeOffice-win64.zip`: the program and the libraries it needs, nothing else.
The installer on the website and the app's own updater fetch their files from here.

This repository holds no source code. The files are proprietary and provided under the
NativeOffice End User License Agreement; see `LICENSE`.

To install by hand, unpack the zip into a folder and run `NativeOffice.exe`. The app
checks for newer releases on launch and installs them itself.
